# Supplemental Material

## Learning-Augmented Combinatorial Solvers: A Solver-Architecture Taxonomy

This repository contains the supplemental material for the paper:

**Learning-Augmented Combinatorial Solvers: A Solver-Architecture Taxonomy**  
by **Morteza Kimiaei** and **Vyacheslav Kungurtsev**

The main article is available as an Optimization Online e-print:

https://optimization-online.org/?p=32520

## Description

This supplemental document provides mathematical background, extended
algorithmic descriptions, and detailed pseudocode supporting the
learning-augmented solver workflows discussed in the main paper.

It includes complete specifications of Algorithms 1--18, covering the ML and RL
components used for propagation, decision making, conflict analysis, restart
control, structural instance analysis, and relational constraint extensions.

The supplement further details differentiable neural logic operators,
reinforcement-learning update rules, graph-based representations, grounding
procedures for relational or finite-domain logical constraints, and disjunctive
programming formulations.

Additional flowcharts, examples, and empirical summaries from the literature are
provided to support and clarify the methods discussed in the main article.
